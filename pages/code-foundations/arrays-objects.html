📦 Arrays and Objects

Arrays store lists of values. Objects store related values under named properties. Most real programs use both together.

Arrays

Example: List of Tasks

const tasks = ["Read", "Practice", "Review"];

console.log(tasks[0]);
console.log(tasks.length);

Objects

Example: User Record

const user = {
  name: "Lena",
  level: "beginner",
  active: true,
};

console.log(user.name);
console.log(user.level);

Using Them Together

Example: Array of Objects

const students = [
  { name: "Mia", score: 95 },
  { name: "Noah", score: 88 },
];

console.log(students[1].name);
