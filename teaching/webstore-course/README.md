# Ecommerce Webstore Codebase Course (10 Weeks)

This packet contains implementation-ready teaching material for mentoring a student who already has coding fundamentals and now needs to become productive in a production ecommerce codebase.

## Contents

1. `weekly-plan.md` - week-by-week teaching schedule with lesson agenda, pair session, solo ticket, and exit criteria.
2. `ticket-bank.md` - ready-to-assign ticket templates mapped to core architecture areas.
3. `code-review-checklists.md` - reusable review forms for weekly mentoring and capstone evaluation.

## How to Use

1. Start from Week 0 prep in `weekly-plan.md`.
2. Assign one ticket each week from `ticket-bank.md`.
3. Run review using the checklist in `code-review-checklists.md`.
4. Track confidence and independence trends weekly.

## Program Outcome

By Week 10, the student should be able to ship a medium feature touching UI, API route logic, provider abstraction, and tests with review-ready quality.
